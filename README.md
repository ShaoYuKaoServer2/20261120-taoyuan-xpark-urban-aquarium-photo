# 🌊 桃園都會型水生公園 — Xpark

> **台灣首座新都會型水生公園**，由日本橫濱八景島團隊打造，結合尖端光影科技、五感沉浸體驗與生態教育，在城市中心重現地球豐富的水生世界。

---

## 📌 專案概述 (Overview)

* **全名**：[Xpark 都會型水生公園](https://www.xpark.com.tw/about)（台灣橫浜八景島股份有限公司）
* **開幕時間**：2020 年 8 月 7 日
* **基地規模**：占地約 4,500 坪，共 3 層樓、13 大主題展區，展示超過 300 種、約 30,000 隻水陸生動物。
* **核心亮點**：
  * **360 度沉浸式空間**：精準控制氣溫、濕度、氣味與聲音，並邀請日本知名音樂家久石讓打造專屬配樂。
  * **科技與生態結合**：融合數位光影投影與「LINNÉ LENS」即時生物圖鑑辨識，提升觀展互動性。

---

## 🗺️ 樓層與 13 大展區架構 (Architecture)

建議參觀動線為 **`2F 入口 ➔ 3F ➔ 2F ➔ 1F 出口`**，完整體驗約需 **2～2.5 小時**。

| 樓層 | 展區名稱 | 核心特色與必看亮點 |
| :--- | :--- | :--- |
| **2F** | **福爾摩沙 (Formosa)** | 4 層樓高巨型大水槽（高 8m、寬 12m），重現台灣周遭海域生態與壯觀的銀鯧魚群風暴。 |
| **2F** | **癒見水母 (Healing Jellyfish)** | 結合無邊際鏡面與萬花筒光影變化，搭配四季色彩呈現水母漂浮的夢幻空間。 |
| **2F** | **企鵝奇遇 (Penguin Life)** | 同時展示國王企鵝與麥哲倫企鵝，設有連結至 1F 咖啡廳的專屬透明水道。 |
| **3F** | **珊瑚潛行 (Coral Diving)** | 180 度環景珊瑚礁水槽，搭配地面投影營造漫步海底的視覺體驗。 |
| **3F** | **暖海生機 (Warm Seas)** | 展示熱帶溫暖海域的豐富生物群像與共生關係。 |
| **3F** | **雨林探險 (Rainforest Adventure)** | 模擬熱帶雨林的濕熱氣候與樹冠層生態，結合聲光雷雨特效。 |
| **3F** | **寒帶行凍 (Cold Regions)** | 設有 360 度透明海豹隧道與巨大昆布之林，可從下方仰望海豹泳姿。 |
| **3F** | **深海尋秘 (Deep Sea)** | 呈現高壓、低溫、無光的深海環境，近距離觀察甘氏巨螯蟹等奇特生物。 |
| **3F** | **虛實互動 (Interactive)** | 親子互動繪畫區，可將手繪海洋生物掃描投影至大型數位海洋螢幕。 |
| **1F** | **漫步叢林 (Walk in the Jungle)** | 打造台灣溪流與河口濕地生態，觀察兩棲類與淡水魚類。 |
| **1F** | **潮間戲灘 (Intertidal Zone)** | 提供預約制潮間帶生態體驗（需額外加購），近距離接觸海洋無脊椎動物。 |
| **1F** | **世外桃源 (Utopia)** | 戶外綠意空間，展示水豚、山羊等陸生可愛動物。 |
| **1F** | **Xcafe by PRONTO** | 日本咖啡連鎖品牌聯名餐廳，可一邊享用美食一邊看企鵝從頭頂透明隧道游過。 |

## ⚠️ 注意事項 (Rules & Tips)

* 館內全面**禁止使用閃光燈、自拍棒與腳架**，以免驚嚇水生動物。
* 禁止攜帶外食（嬰兒副食品與飲用水除外）及寵物（導盲犬除外）。
* 館內**無提供大型行李寄放與置物櫃服務**，攜帶大件行李建議先寄放於高鐵桃園站或機捷 A18 站置物櫃。
